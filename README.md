## 🚀 Cara Menggunakan

### 1. Clone Repository
```bash
git clone https://github.com/jasaaqiqah22-lab/juragan-kambing.git
cd juragan-kambing
```

### 2. Buka di Browser
Cara paling mudah, buka file `index.html` langsung di browser.

### 3. Deploy ke GitHub Pages

1. Push repository ke GitHub
2. Buka Settings repository
3. Pilih "Pages" di sidebar
4. Pilih branch "main" dan folder "/ (root)"
5. Klik "Save"
6. Website akan tersedia di: `https://jasaaqiqah22-lab.github.io/juragan-kambing/`

## 📝 Customization

### Mengubah Konten
1. Buka `index.html`
2. Ubah teks sesuai kebutuhan
3. Ganti placeholder images dengan foto asli

### Mengubah Warna
Buka `css/style.css` dan ubah CSS variables di bagian `:root`:

```css
:root {
    --primary-color: #8B4513;        /* Warna utama */
    --secondary-color: #D2691E;      /* Warna sekunder */
    --accent-color: #FF6B35;         /* Warna accent */
    /* ... */
}
```

### Menambah Gambar
1. Upload gambar ke folder `images/` (buat folder baru jika belum ada)
2. Ubah link placeholder di HTML:
```html
<!-- Sebelum -->
<img src="https://via.placeholder.com/300x200?text=Katering" alt="Katering">

<!-- Sesudah -->
<img src="images/katering.jpg" alt="Katering">
```
